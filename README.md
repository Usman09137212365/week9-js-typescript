# Week 9 — JavaScript Prerequisites & Introduction to TypeScript

## Structure
- `part1-javascript/` — Part 1 tasks (arrow functions, destructuring, spread, template literals, array methods, ternary/&&, ES modules)
  - `index.html` — open this in a browser, console shows all task output
  - `index.js` — all tasks, imports from `utils.js`
  - `utils.js` — named exports (`add`, `capitalize`, `APP_VERSION`) + default export (`formatCurrency`)
- `part2-typescript/` — Part 2 tasks (`.ts` files, not compiled, for instructor review)
  - `1-basic-types.ts`
  - `2-typed-functions.ts`
  - `3-objects-interfaces.ts`
  - `4-arrays-unions.ts`

## How to check Part 1
Open `part1-javascript/index.html` in a browser, then open the console (F12 → Console) to see labeled output for every task.
